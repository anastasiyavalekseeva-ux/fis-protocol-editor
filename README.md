# Подготовка управленческого протокола встречи

Конкурсный скилл `fis-protocol-editor`, версия **2.1.0**.

Скилл превращает краткую сводку и подробный конспект встречи в управленческий протокол: завершённые результаты, следующие действия, исполнители и сроки. Противоречия и неподтверждённые назначения показывает отдельно.

## Полный комплект

[Скачать архив fis-protocol-editor.zip](fis-protocol-editor.zip)

Архив содержит весь конкурсный комплект без изменений: инструкции скилла, справочные материалы, примеры, переносимый валидатор, тесты и доказательства проверок — 114 файлов.

После распаковки начните с `fis-protocol-editor/USAGE.md`. Основная инструкция — `fis-protocol-editor/SKILL.md`, описание задачи — `fis-protocol-editor/TASK.md`, результаты проверок и ограничения — `fis-protocol-editor/VERIFICATION.md`.

Для текстового режима нужны материалы встречи и подтверждённый справочник исполнителей. Для автоматической проверки формата нужен Python 3; параметры приведены в `--help` валидатора.
